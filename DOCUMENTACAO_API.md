# Documentação de API

O projeto não possui API backend. Todas as operações são client-side via localStorage.

Endpoints externos utilizados:
- Google AdSense: https://pagead2.googlesyndication.com/pagead/js/adsbygoogle.js
- Google Fonts: https://fonts.googleapis.com
- PDF.js CDN: https://cdnjs.cloudflare.com/ajax/libs/pdf.js/3.11.174/pdf.min.js

Nenhum endpoint próprio exposto.
